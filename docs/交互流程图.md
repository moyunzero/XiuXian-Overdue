## 3. Ch0 主循环（v4 目标 · R1～R3）

每周 **1 次**「确认本周」，非 4 选 2 抽牌。

```mermaid
flowchart TD
  WeekStart([chapterWeekIndex += 1]) --> Beat{节点周?}

  Beat -->|W4/8/12| Exam[天道审判 · 月考 examBoss]
  Beat -->|W16| Gate16[高中结业 + 筑基审判]
  Beat -->|W17| Gate17[择宗 · 阻塞至完成]
  Beat -->|W22| Audit22[灵气配额审查]
  Beat -->|W28| Gate28[预科结业审查]
  Beat -->|W29| Gate29[择业三轨 + 岗位]
  Beat -->|W32/36| WorkRev[职场 KPI / 催收]
  Beat -->|W40| Finale[契约终审判]
  Beat -->|否| Dash

  Exam --> Dash
  Gate16 -->|通过| DashUni[lifeStage → uni · W17]
  Gate16 -->|失败默认| Degraded["degraded_uni + 污名标签"]
  Degraded --> DashUni
  Gate17 --> DashUni
  Gate28 --> DashWorkPrep[准备 work 段]
  Gate29 --> DashWork["lifeStage → work · W29+"]
  WorkRev --> Dash
  DashWork --> Dash

  Dash[周仪表盘 WeekPlan] --> InboxQ{mandate 队列 > 0?}
  InboxQ -->|是 · 必先| Mandate[仙司来文 · 2-3 回应]
  InboxQ -->|否| Plan
  Mandate --> Plan

  Plan[分配: 还灵贷 / 刷题 / 吐纳 / 零工 / 休息 / 再贷] --> PSY{麻木/驯化阈值?}
  PSY -->|灰按钮| Plan
  PSY -->|保留劣质出路| Tick

  Tick[tickChapterWeek · 日引擎计提息] --> Collapse{崩盘/违约?}
  Collapse -->|是| Archive[征信灵籍 · RunArchive]
  Collapse -->|否| Remain{weeksRemaining > 0?}
  Remain -->|是| WeekStart
  Remain -->|否| Finale

  Finale --> Outcome{ChapterOutcomeId}
  Outcome -->|fulfilled| Archive
  Outcome -->|breach / collapse_*| Archive
  Outcome -->|degraded_*| Archive

  Archive --> EndRun([返回首页 / 新周目])
```

### 3.1 周仪表盘动作（REDESIGN §3.3）

| 动作 | 段 | 备注 |
|------|-----|------|
| `repay` | 全段 | min / partial / extra |
| `study` | hs · uni | 灵籍分 |
| `tuna` | 全段 | 法力 / 破境进度 |
| `parttime` | hs · gig | 波动日结 |
| `work` | work | 主业 KPI |
| `rest` | 全段 | 麻木高时几乎不加专注 |
| `borrow` | 全段 | 以贷养贷 · 驯化↑ |
| `inbox` | 有队列 | 清 mandate，拖后下周+ |

**非节点周**：可「沿用上周分配」一键过周（OQ-4）。

## 5. 仙司来文子流程（mandateDelivery · R3）

取代主路径 `pressureDeck` 4 选 2。

```mermaid
flowchart TD
  M_Start([周初 / 节点后]) --> M_Roll{触发器 · 标签 · 段 · 周次}
  M_Roll -->|0-2 条常规| M_Enqueue[入队 pendingDeliveryIds]
  M_Roll -->|节点周 +1 强制| M_Enqueue

  M_Enqueue --> M_Block{队列 > 3?}
  M_Block -->|是| M_Stop[阻塞新周 · 必须先 inbox]
  M_Block -->|否| M_UI[灵信弹层 / 队列]

  M_UI --> M_Resp{玩家回应}
  M_Resp -->|认赔/执行| M_Apply[effects · 驯化+]
  M_Resp -->|拖延| M_Defer[下周账单+ · 逾期+]

  M_Apply --> M_Done[出队]
  M_Defer --> M_Done
  M_Gray --> M_Done
```

## 附录 A. Legacy `/game` 日槽决策树

> 仅 `/game` 使用 `act(actionId)`；**Ch0 主路径不经过此树**。

```mermaid
flowchart TD
  Start([用户点击行动]) --> IsPending{存在 PendingEvent?}
  IsPending -->|是| Block([拦截输入])
  IsPending -->|否| IsRest{Action == rest?}

  IsRest -->|是| ContractActive{契约已激活?}
  ContractActive -->|是| NumbRoll{Roll 麻木概率}
  NumbRoll -->|成功| NumbEffect[麻木休息: focus+0]
  NumbRoll -->|失败| BacklashRoll{Roll 反噬}
  ContractActive -->|否| NormalRest[正常休息]

  IsRest -->|否| NormalAction[普通行动]
  NumbEffect --> Interest[利息滚动]
  NormalRest --> Interest
  NormalAction --> Interest

  Interest --> EventCheck{事件优先级}
  EventCheck --> NextSlot[推进时段/日结算]
```
