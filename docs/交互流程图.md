## 2. 核心行动决策树 (Action Decision Tree)

每次调用 `act(actionId)` 时的逻辑分流：

```mermaid
flowchart TD
  Start([用户点击行动]) --> IsPending{存在 PendingEvent?}
  IsPending -->|是| Block([拦截输入])
  IsPending -->|否| IsRest{Action == 'rest'?}
  
  IsRest -->|是| ContractActive{契约已激活?}
  ContractActive -->|是| NumbRoll{Roll 麻木概率}
  NumbRoll -->|成功| NumbEffect[执行麻木休息: focus+0, numbness+4]
  NumbRoll -->|失败| BacklashRoll{Roll 反噬概率}
  ContractActive -->|否| NormalRest[正常休息: focus+6*restMult]
  
  IsRest -->|否| NormalAction[执行普通行动主效果]
  BacklashRoll -->|成功| BacklashEvent[弹出反噬弹窗: 强制改行动]
  BacklashRoll -->|失败| NormalRest
  
  NumbEffect --> Interest[利息滚动结算]
  NormalRest --> Interest
  NormalAction --> Interest
  
  Interest --> EventCheck{事件优先级抽检}
  EventCheck -->|1. 身体偿还| Repay[弹出偿还弹窗]
  EventCheck -->|2. 叙事结局| Narrative[弹出结局弹窗]
  EventCheck -->|3. 精神崩溃| Collapse[弹出崩溃弹窗/日志]
  EventCheck -->|4. 随机池| Random[弹出随机事件]
  EventCheck -->|无| NextSlot[推进时间段/日结算]
```

## 3. 借贷与还款子流程 (Economy Sub-flows)

### 3.1 借贷 (Borrow)
```mermaid
flowchart TD
  B_Start([打开借贷弹窗]) --> B_Input[输入金额 Amount]
  B_Input --> B_Limit{Amount <= CreditLimit?}
  B_Limit -->|否| B_Reject[显示额度不足日志]
  B_Limit -->|是| B_Marked{社会评价为 Marked?}
  B_Marked -->|是| B_Surcharge[本金计入 = Amount * 1.2]
  B_Marked -->|否| B_Normal[本金计入 = Amount]
  B_Surcharge --> B_Final[Cash +Amount, Principal +Calc]
  B_Normal --> B_Final
```

### 3.2 还款 (Repay)
还款遵循严格的 **「优先级扣除顺序」**：
```mermaid
flowchart TD
  R_Start([执行还款]) --> R_Seq1[1. 优先偿还 SystemFee]
  R_Seq1 --> R_Seq2[2. 余额偿还 AccruedInterest]
  R_Seq2 --> R_Seq3[3. 余额偿还 DebtPrincipal]
  R_Seq3 --> R_Check{还款额 >= MinPayment?}
  R_Check -->|是| R_Level[逾期等级 delinquency - 1]
  R_Check -->|否| R_Stay[保持逾期等级]
```

## 4. 精神崩溃与总结解锁 (PSY & Summary)

### 4.1 崩溃呈现逻辑
```mermaid
flowchart TD
  C_Trigger([崩溃事件触发]) --> C_History{该 ID 曾触发过?}
  C_History -->|否| C_Full[模式: Full - 弹窗 + 修正激活]
  C_History -->|是| C_Echo[模式: Echo - 仅产生日志回声]
  C_Full --> C_Flag[collapseModifierActive = true]
  C_Flag -->|直到下周| C_Clear[周结算清除修正]
```

### 4.2 总结面板解锁
```mermaid
flowchart TD
  S_Check([每时段后检查]) --> S_Cond1{domestication >= 50?}
  S_Check --> S_Cond2{numbness >= 50?}
  S_Check --> S_Cond3{触发过情节结局?}
  S_Check --> S_Cond4{Day >= 30?}
  
  S_Cond1 -- OR --> S_Unlock[summaryUnlocked = true]
  S_Cond2 -- OR --> S_Unlock
  S_Cond3 -- OR --> S_Unlock
  S_Cond4 -- OR --> S_Unlock
```
