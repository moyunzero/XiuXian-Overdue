## 1. 设计尺子（不可漂移）

| 尺子 | 含义 | 反模式 |
|------|------|--------|
| **迫切感** | 下月洞府租、下周灵气配额、契约到期利息——时间有牙 | 400 回合 realm 跑步机、optimiser 0% 崩盘 |
| **可计算的恶意** | 玩家能说「我早知道会输，但还是签了灵贷」 | 纯数值条蠕动、无灵籍/账单界面 |
| **黑色幽默** | 灵信、征信、宗门章程口吻冷而荒谬 | 宗门爽、战力榜、刷牌爽感 |
| **灵魂保留** | Act1 桌面、身体/寿元抵押、StartConfig 因果 | 丢弃前奏或把抵押做成一次性彩蛋 |
| **现实可指认** | 试玩者能说出「这段像现实中的 ___」 | 只有修仙名词、对不上任何生活经验 |

玩家可见文案与标签：继续遵守 `.cursor/rules/player-facing-copy.mdc`。**文档与 UI 统一禁用「制度」作玩家可见词**；代码注释可用「天规层」指代本设计域。

### 2.2 《没钱修什么仙？》气质对照（非剧情复刻）

| 原著意象 | 本作 Ch0 对应 | 禁止 |
|----------|---------------|------|
| 嵩阳高中、面试签器官/灵根检测 | Act1 面试 + S0 三步 | 原著人名入库 |
| 天庭 **百年功力贷**、日息半天功力 | 灵贷复利、**minPay**、代扣 | 纯 fantasy 贷款无条款 |

### 2.3 四十周 = 契约账期（非真实日历）

现实里高中→大学→职场跨越 **数年**；Ch0 用 **40 个契约周** 压缩，叙事 framing 固定为：

> **每一周 = 灵贷契约上的一个账期窗口**；人生阶段靠 **关口审查**（月考、择宗、择业）标记，而非假装「第 17 周上大学」等于现实第 17 周。

试玩验收 **V4-7**：玩家能指认至少 **3 组**「现实像 ___ / 游戏里叫 ___」（见 §8）。

### 3.2 与 v3 的差异（必须写进实现验收）

| v3（废弃为主路径） | v4 |
|-------------------|-----|
| 每回合 `offeredCardIds` 四选二 | 周为主节拍；牌/来文为**仙司外来**，非日常行为菜单 |
| `runMode: endless` + realm 叠层 | `chapterId` + 明确 **win / collapse / archive** |
| `advanceLifeSegment` 自动推进人生 | 章节内推进；段间仅经 **天道审判关**，非静默换 `lifeStage` |
| PSY 在 play 路径多为占位 0 | 麻木/驯化 **锁按钮、灰决策**，走主路径 |

### 3.3 周决策动作（MVP · 锁定）

> 每周玩家在仪表盘完成 **1 次「本周怎么活」确认**（可预填上周计划）；**不是**从牌堆抽 4 选 2。

| 动作 ID | 玩家可见名 | 段内可用 | 消耗 | 主要产出 | 现实像 |
|---------|------------|----------|------|----------|--------|
| `repay` | 还灵贷 | 全段 | 灵石 | 降逾期、保征信 | 还最低还款 / 提前还 |
| `study` | 刷题 | hs·uni | 精力 | 灵籍分、月考备 | 补课、预科 |
| `tuna` | 吐纳 | 全段 | 精力 | 法力/破境进度 | 修炼（机会成本） |
| `parttime` | 散修零工 | hs·gig 轨 | 精力 | 现金（波动） | 日结、跑腿 |
| `work` | 主业出勤 | work | 精力 | 时薪/KPI | 上班、冲 KPI |
| `rest` | 硬睡 | 全段 | — | 减疲劳；**麻木高时几乎不加专注** | 补觉但脑子仍木 |
| `borrow` | 再贷一笔 | 全段 | — | 现金↑ 债务↑ 驯化↑ | 以贷养贷 |
| `inbox` | 应来文 | 有队列时 **必先** | — | 清队列；拖后则下周账单+ | 点开催收/通知 |

**节点周**（W4/8/12/16…）：先插入 setpiece，再回到仪表盘或直接进入周结算。  
**非节点周**：允许「沿用上周分配」一键过周（见 §10 OQ-4）。

## 4. 章节制（方向 C 落地）

### 4.1 Chapter 0（MVP — 已锁定）

**Chapter 0 —「四十周灵贷契约」**（`chapterId: ch0-forty-week-contract`）

| 要素 | **锁定值** |
|------|------------|
| **契约时钟** | 自 Act1 结转后起算，**剩余 40 周**（`chapterWeekBudget: 40`，每周推进 1，不可购买「续期」为主路径） |
| **人生覆盖** | **全做**：`hs` → `uni` → `work`（禁止静默跳过；段间仅经 **审判关** 闸门） |
| **职场出口** | 三轨择业（玩家可见名）：**进公司（宗门文书岗）** / **创业（挂靠工作室）** / **散修零工（灵活就业）** |
| **实玩目标** | **75～120 分钟**（含 Act1 15～25 分）；契约周 UI 常显「剩余 N 周」 |
| **章节终点** | ① **W40 终审判** 通过 → **征信灵籍**（履约/升职/降档）；② 崩盘（债务/身体/断供/审查）；③ **契约违约** |
| **破境** | 章节内 **里程碑**（建议 W16 筑基关口），**不是**无尽 realm 叠层；紫府+ 不进入 Ch0 |
| **非目标** | 400 回合跑步机；4 选 2 每回合抽牌；无尽 `realmTemplates` 主路径 |

**与 Act1 关系**：S0 仍为独立序幕（桌面三模块）；结转写入 `StartConfig` / 利率 / 家庭标签后，**Ch0 周计数从 1 开始**，界面显示「灵贷契约剩余 40 周」。

#### 4.1.1 四十周节拍（草案 — 实现以 PLAN 为准）

```text
周次    段落        天规脊梁（Setpiece 示例 · 现实指认）
────────────────────────────────────────────────────────────
1–16    高中 hs     月考/分班（W4·8·12·16）→ 像期末/分流
                    W16 筑基审判（可失败崩盘）→ 像高考/结业关
        ↓ 审判关：预科资格 / 灵贷额度重估
17–28   大学 uni    择宗（W17）；灵气配额审查（W22）；预科结业（W28）
        ↓ 审判关：毕业灵籍 / 就业准入
29–40   职场 work   择业三轨（W29）；KPI/催收（W32·36）；W40 契约终审判
                    → 像入职/试用期/合同到期
```

> 16+12+12=40。段落内用 **周仪表盘 + 仙司来文** 填充日常，不在此表堆事件 JSON。

#### 4.1.2 职场三轨（MVP · 现实机制差）

| 轨道 | 玩家标签 | 现实指认 | 现有资产 | v4 需补 |

#### 4.1.3 Act1 → Ch0 结转（字段级 · MVP）

Act1 结算后 `advanceRunToHs` / `ensureHsRunReady` 已合并账本；v4 在此基础上 **额外初始化章节时钟**。

| 来源 | 写入 Ch0 | 玩家可感 |
|------|----------|----------|
| `StartConfig.background` | 初始现金、基础日息 | 贫民更紧、富户缓冲更大 |
| `StartConfig.talent` | 法力/专注初值 | 修炼与刷题效率 |
| `StartConfig.initialDebt` | 无 Act1 贷款时的本金底 | 开局欠多少 |
| `Act1State.loans` + `cash` | `mergeAct1LedgerIntoHsEcon` → 本金/利息/加权日息 | 「入学前夜结转负债 ¥…」 |
| `Act1State.profileTags` | 最多 **3** 条进 `profileTags` | 灵籍备注、来文池权重 |
| `Act1Interview` 结果 | 标签 + 分班倾向 | 末位借读 / 附条件 / 特招 |
| `Act1Carryover.interestRateMultiplier` | `dailyRate` 叠乘 | 家庭担保 +8% 等 |
| `Act1Carryover.startingDelinquencyBias` | `delinquency` 起步 | 征信已有污点 |
| `Act1Carryover.metaUnlocks` | 标签 + 灵信提示 | 跨周目备注 |
| **v4 新增** `chapterWeekIndex` | **1**；`weeksRemaining` **40** | 顶栏「契约剩余 40 周」 |
| **v4 新增** `lifeStage` | **hs**（仅经闸门变更） | 段标签「高中」 |

**日历单一真相**（与 SCHEMA 一致）：`chapterWeekIndex` 1…40 为主计数；`weeksRemaining = 40 - chapterWeekIndex`；`school.week` 与 `chapterWeekIndex` **同步递增**，Act1 结转后二者从 **1** 起算。

**StartConfig 因果示例（试玩用 · 非穷举）**

| 组合 | Ch0 差异 |
|------|----------|
| 贫民 + 无灵根 + 高 initialDebt | 现金紧、日息高、首月即来文催收 |
| 中产 + 伪灵根 + Act1 比价标签 | 利率略低但「比价」备注触发额度审查 |
| 特招面试 + 家庭 `saved-costly` | 高日息 + 偶发「家庭担保」来文 |

实现入口：`createHsPlayState.ts`、`act1Carryover.ts`；v4 在 `initChapter0()` 补章节字段。

#### 4.1.4 家庭线在 Ch0（延续 Act1 · 非可选）

| `familyOutcome` | Ch0 持续效果 | 现实像 |
|-----------------|--------------|--------|
| `left` | 无家庭担保；**不**发家庭来文；部分额度选项永久缺失 | 监护人迁出、紧急联系人空 |
| `saved-costly` | 已付挽留金；利率乘数已叠；W32+ 低概率「担保人问询」来文 | 家人留下但背担保债 |
| `saved-false-hope` | 周转贷已入账；**更高频**「家庭周转」来文；`familyResilience` 锁低 | 以贷养家的假缓解 |

防卡点：家庭相关来文 **不得** 阻塞无回应路径超过 2 周（拖后计息，而非 soft-lock）。回归：`act1FamilyFlow.spec.ts` + Ch0 流程 spec 各 1 条家庭标签路径。

### 4.2 章节结局（Ch0 · MVP 最小集）

| 结局 ID | 玩家可见名 | 触发（任一满足） | 征信灵籍必写 |
|---------|------------|------------------|--------------|
| `fulfilled` | 契约履约 | W40 终审判通过 | 履约档、岗位符、剩余债务 |

| `collapse_body` | 抵押崩盘 | 身体完整度/抵押赎回失败 | 留置部位、完整度 |
| `collapse_review` | 审查崩盘 | 关键审判关失败 **且** 无降级路 | 挂科/审查词条 |

## 5. 天规节拍（方向 B 落地）

### 5.1 三层时钟

| 层 | 周期 | 玩家动词 | 系统职责 |
|----|------|----------|----------|
| **日** | 可选简化 | 微调（回灵信、点账单） | 利息计提、疲劳 |
| **周** | **主循环** | 仪表盘分配精力/灵石/还款 | `advancePlayRunCalendarDay` 类逻辑保留，但 **UI 以周为屏** |
| **月/节点** | Setpiece | 应诉、大考、抵押 | 复用 `setpieceFlow` / `examBoss` / `bodyMortgage`，升格为**章节脊梁** |

### 5.2 压力牌 JSON → 仙司来文

| 旧模型 | 新模型 |
|--------|--------|
| `PressureCardDef` = 玩家「这回合做什么」 | `MandateDelivery` = 仙司/宗门「这账期对你做什么」 |
| 4 选 2 优化解法 | 2～3 个**回应**（认赔/拖延/硬扛/走灰产），拖延加重下周账单 |
| `pressureDeck.startRound` 每回合发牌 | 灵信 `inbox` + **强制弹层** + 周结算排队 |

**数据**：可迁移 `pressureCards.json` 文案与触发器，但 **schema 与 offer 逻辑重写**；禁止仅改文案继续 4 选 2。

**来文示例（玩家可见口吻）**

| 来文类型 | 现实像 | 昆墟文案方向 |
|----------|--------|--------------|
| 催收 | 银行/平台逾期提醒 | 「灵贷中心：您已逾期 **N** 账期…」 |
| 抽检 | 合规检查、社保稽核 | 「执法队：洞府灵气用途抽检」 |
| 加班通告 | 996 通知 | 「宗门文书：本月 KPI 灵材入库量」 |
| 冻结预告 | 额度/征信冻结 | 「征信灵籍：预冻结修炼配额」 |

### 5.3 PSY / 麻木 / 驯化（主路径）

参考 [PSY系统与叙事螺旋.md](./PSY系统与叙事螺旋.md) 与 `gameEngine` 契约逻辑，在 `PlayRunState` 显式字段化（当前 play 路径多处写死 `0`）。

| 指标 | 玩家可感表现 | 现实像 |
|------|--------------|--------|
| **驯化** | 灵信选项变少、默认勾选「收到」 | 习惯性回复「收到」、不再争辩 |
| **麻木** | 仪表盘按钮变灰；「休息」不回专注，仅减疲劳 |  burnout：知道要睡但选了也无用 |
| **崩溃** | Full 弹窗 + 当周收益修正；Echo 仅日志 | 短期崩溃后硬撑上班 |

**边界（v4.2 新增）**：麻木锁的是**最优解按钮**，须保留 1～2 条劣质出路（拖、借、灰产）——对应现实中的以贷养贷、硬扛、走黑产；**禁止**整屏无可点项。

### 5.4 身体 · 债务 · 权限（锋利化）

| 线 | 保留 | v4 加强 | 现实像 |
|----|------|---------|--------|
| **债务** | 复利、逾期、最小还款 | **断供反噬**：连续未达 minPay → 灵气/洞府降级 → 修炼收益坍塌 | 断供、征信恶化、生活成本级联 |
| **身体** | 抵押、赎身、完整度 | **负债化**：义体老化/灵根污染随周衰减；抵押非一次性 buff | 体检贷、器官抵押、过劳损耗 |
| **权限** | 分数/分班/岗位 | 与额度、来文池、审判选项挂钩；**灵籍分**比境界数字更可感 | 档案分、HR 标签、岗位符 |

## 7. 技术迁移（逻辑层，无 Pinia）

原则：**规则仍在 `app/logic/*`**；composable 只编排；logic 禁止 import vue/pages。

### 7.1 类型（`app/types/play.ts` 草案）

```ts
// 示意 — 完整形状见 SCHEMA.md § ChapterConfig
type RunMode = 'chapter' | 'endless' // endless 迁移期只读
type ChapterId = 'ch0-forty-week-contract' | (string & {})

interface ChapterRunState extends PlayRunState {
  chapterId: ChapterId
  chapter: {
    weekBudget: number // 来自 getChapterConfig(id).weekBudget
    chapterWeekIndex: number
    weeksRemaining: number
    outcomeId?: ChapterOutcomeId
  }
  mandate: MandateState
  // pressure 主路径 deprecated
}
```

存档：`saveSchemaVersion` bump 须带 **v5→v6 章节档迁移** spec。

### 7.2 建议实施波次

| 波 | 交付 | 验证 |
|----|------|------|
| **R0 设计锁** | 本文 + `docs/planning/R-chapter-0/PLAN.md` | 团队对齐 |
| **R1 骨架** | 40 周契约时钟 + 三段 `lifeStage` 闸门 + 废弃 endless 主路径 | `chapter0-contract-flow` + `HARNESS_OK` |

**明确暂停**：M-balance 无尽长跑调参、紫府/结丹被动压力（除非服务于 Ch0 终点前）。

### 7.3 扩展架构（禁止写死 · v4.4）

Ch0 是 **第一份 `ChapterConfig`**，不是 logic 里的特例。后续 Ch1、变长契约、新段落 **只增数据 + registry 注册**，不复制 `if (week === 16)`。

| 层 | 职责 | 写死禁止 |
|----|------|----------|
| **`data/chapters/{id}.json`** | weekBudget、segments、beats、gates、mandatePools | 禁止在 TS 写死 40 / 16 / 29 |
| **`chapterRegistry.ts`** | `getChapterConfig`、`segmentForWeek`、`beatsForWeek` | 禁止按 chapterId 分叉大段 logic |
| **`beatRunner.ts` + `BEAT_HANDLERS`** | 节点 kind → 已有 handler | 禁止在 `tickChapterWeek` 里 switch(week) |
| **`openSegmentGate`** | 唯一写 `lifeStage` | 禁止 `advanceLifeSegment` 静默换段 |
| **`mandateDelivery.roll`** | 读 config 池 + tags | 禁止主路径 4 选 2 |
| **`resolvePlayScreen`** | 表驱动 UI 屏 | 禁止 `play/index.vue` 无限 v-else-if 增分支 |

完整模块图、Ch1 checklist、R1 anti-hardcode 项 → [EXTENSIBILITY.md](./planning/R-chapter-0/EXTENSIBILITY.md)。  
示例配置 → [chapter-config.example.json](./planning/R-chapter-0/chapter-config.example.json)。

**加内容 vs 加章节**

| 你想做 | 改什么 | 不改什么 |
|--------|--------|----------|
| 多几条催收来文 | `data/mandates/ch0-*.json` | `tickChapterWeek` |
| 新 job / 新轨 | `jobs.json` + track 过滤 | 周循环 |
| 新节点周 W24 | config `beats` + handler 注册 | 段落表散落 if |
| 新一章 Ch1 | 新 `{id}.json` + flow spec + 入口 | 复制 chapterWeekFlow |
