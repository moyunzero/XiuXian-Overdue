## 一、核心数学模型与推导

### 1.1 月考评分公式 (Exam Scoring)
月考评分旨在通过境界（Stats）决定分层，同时受负面状态压制。
```text
Score = Base(520) + Stats_Gain + Bonus - Penalties + Noise
```
- **Stats_Gain (境界收益)**: `daoXin*8 + faLi*6.5 + rouTi*35`。
  - *设计意图*: 1 点肉体强度等效于 5.4 点法力，强调炼体在高压下的提分效率。
- **Penalties (负面压制)**:
  - **债务压制**: `Math.min(18, Math.log10(1 + totalDebt / 1000) * 6)`。使用 Log10 确保债务对分数的影响在后期边际递减，不至于让巨额债务导致考试必然挂科。
  - **疲劳压制**: `Math.max(0, (fatigue - 55) * 0.25)`。55 点为疲劳安全水位，超过后每点扣除 0.25 分。
- **Noise (随机抖动)**: `(rand() - 0.5) * 14`。约 ±7 分的波动，增加排名竞争的悬念。

### 1.2 身体部位动态估值 (Dynamic Valuation)
部位估值并非固定，而是基于「个体价值」的资产化。
```text
Valuation = Base_Price[part] * Cultivation_Mult * (1 - Fatigue_Penalty) * (1 - Debasement_Penalty)
```
- **Cultivation_Mult (修为倍率)**: `1 + faLi * 0.1 + rouTi * 0.2`。境界越高，部位在黑市/官方系统中的溢价越高。
- **Debasement_Penalty (补剂惩罚)**: `buyDebasement * 0.05`。吃药越多，身体「杂质」越多，回收价值越低。

## 二、3D 视觉映射逻辑 (Three.js Integration)

### 2.1 模型节点控制
`HumanModelViewer.vue` 加载 `human-body.glb`，并通过深度监听 `GameState.bodyPartRepayment` 对象实现部位显隐。

| 身体部位 (partId) | 对应的 GLB Mesh 节点名 | 偿还后的视觉效果 |
| :--- | :--- | :--- |
| **LeftPalm** | `Hand_L` | 隐藏 Mesh / 应用 Wireframe 材质 |
| **RightPalm** | `Hand_R` | 隐藏 Mesh / 应用 Wireframe 材质 |
| **LeftArm** | `Arm_L` | 隐藏 Mesh |
| **RightArm** | `Arm_R` | 隐藏 Mesh |
| **LeftLeg** | `Leg_L` | 隐藏 Mesh |
| **RightLeg** | `Leg_R` | 隐藏 Mesh |

### 2.2 视觉反馈流程
1.  用户在 `EventModal` 选择偿还部位。
2.  `resolveEvent` 更新 `game.bodyPartRepayment[partId] = true`。
3.  `HumanModelViewer` 监听到响应式数据变化。
4.  执行 `Object3D.visible = false`，并触发一次粒子消散特效（如果已实现）。

## 三、UI 组件通信与交互协议

### 3.1 状态注入逻辑
项目不使用传统的 Vuex/Pinia，而是利用 Nuxt 的 `useState` 封装。
- **注入点**: 根组件 `app.vue` 初始化状态。
- **获取点**: 各业务组件通过 `const { game } = useGameState()` 获取响应式指针。

### 3.2 弹窗冲突协议 (Modal Stack)
为防止多个弹窗重叠导致的逻辑混乱，系统遵循以下协议：
1.  **PendingEvent 锁**: 只要 `game.pendingEvent` 不为空，所有的 `StatPanel` 行动按钮将被 `disabled`。
2.  **还款/借贷弹窗**: 属于临时 UI 状态，不存储于 `GameState`。它们在打开时会暂停 `endDay` 自动推进（通过阻塞 `act` 入口）。

## 四、数值边界与溢出处理 (Constraints)

| 字段 | 最小值 | 最大值 | 溢出逻辑 |
| :--- | :--- | :--- | :--- |
| **fatigue** | 0 | 100 | `clamp(val, 0, 100)` |
| **focus** | 0 | 100 | `clamp(val, 0, 100)` |
| **dailyRate** | 0.004 | 0.05 | 周结算时进行 `Math.min(0.05, rate)` 封顶 |
| **delinquency** | 0 | 5 | 逻辑上可无限增长，但 `DELINQUENCY_POLICIES` 仅定义至 5 级（5级以上复用5级配置） |
| **bodyIntegrity** | 0.262 | 1.0 | 0.8 的 6 次幂为理论下限 |
