## 1. 核心属性联动（Stats）

| 属性字段 | 联动逻辑 | 事件效果建议 (Delta) |
| :--- | :--- | :--- |
| **daoXin (道心)** | 影响吐纳收益。事件中极少改动，仅在「撒谎/坦白」等重大决策中微调。 | ±1 |
| **faLi (法力)** | 核心成长指标，决定月考分数。事件多为「短期大幅提升」或「强制抽取」。 | +0.1 ~ +0.3 |
| **rouTi (肉体强度)** | 影响月考分数。事件中常作为「身体偿还」或「霸凌」的负面减损项。 | +0.05 ~ +0.1 / -0.05 |
| **fatigue (疲劳)** | 高疲劳导致「训练受伤」与「叙事结局」。几乎所有事件都会伴随疲劳波动。 | ±4 ~ ±15 |
| **focus (专注)** | 影响上课收益。所有消耗注意力的决策都会扣减专注。 | ±2 ~ ±10 |

## 2. 经济系统联动（Econ）

| 字段 | 联动规则 | 事件效果建议 |
| :--- | :--- | :--- |
| **cash (现金)** | 支付补给、偿还债务、应对突发。事件中的 cash delta 应与背景设置挂钩。 | ±50 ~ ±1000 |
| **debtPrincipal (本金)** | 借贷或强制重组时增加。增加本金会提高后续所有利息滚动基数。 | +80 ~ +500 |
| **debtInterestAccrued (利息)** | 每时段自动滚动。事件中可通过「债务重组」大幅转嫁。 | +30% 滚动债 |
| **collectionFee (费用)** | 制度惩罚项。优先于本息偿还，由「系统维护」、「路线抽检」产生。 | +45 ~ +200 |
| **delinquency (逾期)** | 核心风险等级。影响事件触发概率与核心债重估。 | +1 / -1 |

## 3. 制度性事件：身体偿还（优先级最高）

身体偿还事件不通过 `events.json` 配置，而是由代码根据动态估值（`calculateDynamicValuation`）生成。

### 3.1 价值评估联动
- **法力/肉体加成**：`1 + faLi * 0.1 + rouTi * 0.2`（境界越高，部位越值钱）
- **负面惩罚**：
  - 疲劳：`fatigue > 70` 时，每点扣 1%
  - 劣化：`buyDebasement * 0.05`（吃药越多，部位越贬值）
- **保底价**：基础价格的 20%。

### 3.2 后果联动
- **债务冲减**：`totalPaid = min(valuation, rollingDebt)`（不冲减核心债）。
- **身体完整度**：`bodyIntegrity *= 0.8`（永久降低所有后续行动的增益，提高疲劳消耗）。
- **社会评价**：`bodyReputation = 'marked'`（永久上调借贷本金 1.2x，上调补给价格 1.15x）。
- **延迟叙事**：3 天后触发对应的「身体感受」日志，产生心理暗示。

## 4. 契约与 PSY 系统联动

### 4.1 契约反噬（Backlash）
- **触发逻辑**：根据 `vigilance` 概率拦截「休息」或「摸鱼」行为。
- **数值强制**：
  - `被迫吐纳/刷题`：强制消耗疲劳，强制提升法力，强制增加 `contract.progress`。
  - `硬抗`：大幅扣减专注（-16），增加监工警觉（+10），增加利息（+120）。

### 4.2 驯化与麻木（PSY-01/05）
- **同步规则**：每次 `progress` 或 `vigilance` 正向增加时，`domestication` 同步提升（`add = dp*0.28 + dv*0.12`）。
- **麻木积累**：中后期（Day >= 10）休息时，有概率（最高 55%）进入「麻木休息」，专注不回，`numbness +4`。

## 5. 路线偏科联动（Streak System）

系统每日结算（`endDay`）会根据当日行动类型判定：

- **刷分路线（Study/Tuna）**：
  - 连续 ≥ 2 天：触发「制度抽检」概率增加，法力增益倍率下调（`1 - 0.065*(streak-1)`）。
- **打工路线（Parttime）**：
  - 连续 ≥ 2 天：打工收益倍率下调（`1 - 0.055*(streak-1)`）。
- **共通后果**：
  - 事件触发概率上调 **0.08**。
  - 每隔 2-3 天触发一次「路线失衡」制度日志。
