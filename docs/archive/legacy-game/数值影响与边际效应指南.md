## 1. 资源增益的复合权重分析 (Compounding Weights)

### 1.1 最终收益公式 (Final Gain Model)
单次行动（study/tuna/train/parttime）的收益由以下公式决定：
`Gain = Base * FocusMult * TierMult * IntegrityMult * StreakMult * CollapseMult`

| 因子 | 最小值 | 最大值 | 关键影响因素 |
| :--- | :--- | :--- | :--- |
| **FocusMult** | 0.5x | 2.0x | `focus` 每 10 点约改变 0.15x 增益。 |
| **TierMult** | 0.9x | 1.12x | 示范班 (+12%) vs 末位班 (-10%)。 |
| **IntegrityMult** | 0.26x | 1.0x | 每次部位偿还后固定 × 0.8。 |
| **StreakMult** | 0.72x | 1.0x | 连续刷分/打工第 2 天起每日递减 6.5%/5.5%。 |
| **CollapseMult** | 0.88x | 1.0x | 精神崩溃后的全局 Debuff。 |

## 2. 边际效应与生存陷阱 (Marginal Traps)

### 2.1 身体完整度的「死亡螺旋」
玩家偿还部位以冲减债务，但其代价是非线性的。
- **疲劳放大器**: `ActualFatigue = BaseFatigue * (2 - bodyIntegrity)`。
- **定量分析**:
  - 偿还 2 部位 (Integrity 0.64): 增益剩 64%，疲劳消耗 1.36x。**净效率 = 47%**。
  - 偿还 4 部位 (Integrity 0.41): 增益剩 41%，疲劳消耗 1.59x。**净效率 = 25%**。
- **结论**: 偿还超过 3 个部位后，通过正常行动维持现金流的能力会断崖式下跌，系统性恶意将迫使玩家进入「全方位麻木」状态。

### 2.2 专注度 (Focus) 的策略平衡
- **55 点分界线**: 55 点以下考试分数受罚；55 点以上收益线性增长。
- **最优区间**: 维持在 70~85。过高会导致「买药」性价比降低，过低则月考评分不保。

## 3. 策略博弈：两种极端的生存方式

### 3.1 刷分流 (Scholar Strategy)
- **目标**: 维持示范班，换取 12% 增益加成与 ¥160/日的餐补。
- **数值门槛**: 法力 > 10, 肉体 > 2。
- **博弈点**: 示范班的餐补足以支付 0 逾期状态下的部分利息，形成正向循环。

### 3.2 违约流 (Strategic Delinquency)
- **目标**: 通过 3 级以上逾期诱发「身体偿还」，一次性冲减 ¥8,000 ~ ¥18,000 滚动债。
- **数值博弈**: 在法力 > 15 时偿还部位，利用「修为溢价」(`1 + faLi*0.1`) 极大化部位价值。
- **长期代价**: `marked` 状态带来的 1.2x 借贷本金上浮，会彻底锁死玩家通过「借新还旧」苟活的可能性。

## 4. 风险控制边界 (Risk Thresholds)

| 场景 | 关键数值 | 判定后果 |
| :--- | :--- | :--- |
| **利率封顶** | `dailyRate = 5%` | 逾期 5 级且经多次风控上浮。 |
| **内伤风险** | `fatigue > 60` | 炼体 (train) 开始产生受伤概率。 |
| **叙事结局** | `fatigue 90 / focus 15 / delinquency 3` | 触发一次性叙事日志，解锁总结面板。 |
| **崩溃门控** | `Score / 520 > 0.48` | 精神压力分数超过 250 时，崩溃概率达到上限。 |

## 5. 开发者调优建议
- **如果玩家通关太容易**: 调高 `collectionFee` 的周增长速度（当前为 600 + 200*L）。
- **如果玩家过早死亡**: 调低 `IntegrityMult` 的衰减系数（从 0.8 改为 0.85）。
- **如果偏科路线无敌**: 缩短 `StreakMult` 降至 0.72x 所需的天数。
