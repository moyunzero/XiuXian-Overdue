## 0. 试玩前（主持人 · 15 分钟）

### 环境

- [ ] 本地或预览 URL 可访问：`yarn dev` → `http://localhost:3000`，或已部署 preview
- [ ] **硬刷新 / 无痕窗口**，避免旧存档干扰（存档 key：`kunxu_sim_save_v5`，schema **v6**）
- [ ] 浏览器：**Chrome / Safari 桌面**优先（移动壳 I1 未做，手机仅作附加记录）
- [ ] 宽屏检查：Play 页无右侧黑边（全宽布局）

### 工程门禁（交付基线，非玩家项）

- [ ] `yarn harness:verify` → **HARNESS_OK**（试玩前至少 `--quick`）
- [ ] 确认当前分支含 **chapter 主路径**（非仅 v3 endless）

### 材料

- [ ] 打印或复制 **[附录 A 记录表](#附录-a-单局记录表)**（每位玩家 1 份）
- [ ] 准备 **[附录 B 玩家提示卡](#附录-b-玩家提示卡可转发)**（口头说明亦可）
- [ ] 录音/录屏 **征得同意**；标注设备与分辨率

### 招募建议

| 项 | 建议 |
|----|------|
| 人数 | **2～3 人**（首轮）；后续可扩到 5 人 |
| 画像 | 非开发者；能读中文 UI；**未读过** REDESIGN / 交互流程图 |
| 分组 | 至少 **1 人**尝试不同 `StartConfig`（家庭/灵根/地区各改一项） |
| 三轨 | 完整局时：3 人各选 **进公司 / 散修零工 / 挂靠创业** 一条（W29） |

### 主持人原则

- **不剧透**机制与数值；不提示「正确玩法」
- 只在 **卡死 >3 分钟** 或 **明显 bug**（白屏、按钮无反应）时介入
- 记录原话，尤其是：**困惑句、关游戏冲动、黑色幽默反应**

## 1. 短局脚本（45～60 分钟 · 推荐首轮）

> 目标：验证 **V4-2**（10 分钟内懂主循环）+ **V4-7**（现实映射）+ Act1 情绪铺垫。

| 分钟 | 阶段 | 玩家做什么 | 主持人观察 |
|------|------|------------|------------|
| 0–2 | 首页 | 自定义开局 → **开始修行** | 是否只有一个清晰入口；StartConfig 是否敢点 |
| 2–15 | Act1 入学前夜 | 面试 → 灵贷 → 家庭线（最短路径） | 烦躁 vs 代入；是否懂「签了什么」 |
| 15–18 | 结转 Ch0 | 进入 `/play`，看到契约周 | 是否出现「选两张牌」误解（**应无** 4 选 2） |
| 18–28 | 周仪表盘 W1–3 | 调还款/吐纳/零工/休息 → **确认本周** | 是否理解「账期」；债务/精力是否可读 |
| 28–38 | 来文 + W4 月考 | 处理仙司来文；月考 setpiece | 来文是否像「被甩脸」；月考是否像审查关 |
| 38–45 | 自由 2～3 周 | 可「沿用上周」过周 | 非节点周是否过慢/过快；想关游戏时刻 |

**短局结束访谈**（5 分钟，见 [§4](#4-结束访谈必问)）— 不必打满 W40。

## 2. 完整局脚本（75～120 分钟 · 第二轮）

> 目标：验证 **V4-1 / V4-3 / V4-5 / V4-8** 对应的**人玩**部分（模拟器已覆盖理性崩盘率）。

| 段落 | 契约周 | 必经历节点 | 主持人勾选 |
|------|--------|------------|------------|
| Act1 | — | 面试 + 灵贷 + 家庭 | ☐ 情绪 ≥3/5 |
| 高中 | W1–16 | 月考 W4/8/12；**W16 筑基审判** | ☐ 感到「下周要还钱」 |
| 大学 | W17–28 | **W17 择宗**；W28 预科结业 | ☐ 升学像「关口」非静默换屏 |
| 职场 | W29–40 | **W29 三轨择业**；W40 终审判 | ☐ 三轨差异可感知 |
| 结局 | W40 或崩盘 | 征信灵籍 / 崩盘归档 | ☐ 能复述三条欠账（V4-5） |

**完整局额外观察**

- [ ] 顶栏常显 **「灵贷契约剩余 N 周」** 与段标签（高中/大学/职场）
- [ ] **PSY 灰按钮**：麻木时「刷题/吐纳」变灰；驯化时部分还款档变灰（若触发）
- [ ] 断供链：连续未达最低还款 → 是否有 **断供/征信** 反馈（非 silently 扣血）
- [ ] 崩盘（若发生）：原因是否 **可解释**（债务 / 身体 / 审查），非「突然死了」

## 4. 结束访谈（必问）

用 **开放式** 提问，避免引导「你应该觉得窒息」。

1. **用一句话**：这局你在「过什么日子」？
2. **最难受的一刻**是什么？为什么？
3. **最懂规则的一刻**是什么？（对应 C1）
4. **有没有像现实里的什么**？（对应 V4-7，至少挖 3 组）
5. **如果真实存在这种灵贷**，你会签吗？游戏里你为什么还签/不还？
6. **三档打分**（1～5）：剧情 / 系统 / 情绪  
   - 任一项 **≤2** → 记录具体 UI 或文案
7. **会不会开第二局**？为什么 / 为什么 not？
8. （完整局）**结局档案**里，你觉得自己 **欠了什么**？

## 附录 B：玩家提示卡（可转发）

> 发给试玩者即可，不含剧透。

**这是什么**  
单机 Web 修仙生存模拟：你签了 **灵贷契约**，要在 **40 个账期周** 里还清债务、保住身体、拿到权限。

**怎么玩**

1. 先完成 **入学前夜**（面试、贷款、家里的事）。
2. 进入主界面后，每周在 **周仪表盘** 决定：还多少灵贷、吐纳/刷题/零工/休息怎么分配。
3. **灵信里的仙司来文** 会强制出现 — 需要先处理再推进（像催收和通知）。
4. 到 **月考、筑基、择宗、择业** 等节点会有全屏「关口」；按提示操作。
5. 契约 **剩余 0 周** 或 **还不清/身体垮/审查不过** 会结束一局，查看 **征信灵籍** 档案。

**请随意**

- 没有唯一正确答案；可以摆烂、可以硬还、可以冒险。
- 卡住了可以说出来，主持人只帮排除 bug，不教最优解。
- 想到 **「这像现实中的什么」** 随时说出来，我们在收反馈。

**时长**  
短试玩约 **45 分钟**；完整一局约 **1.5～2 小时**（可分段）。
